# 부서별 실태조서 입력 양식

부서별 지정 양식과 23개 수련과별 집담회 양식을 작성합니다.
영상의학팀은 작성 범위 미지정으로 입력에서 제외합니다. 집담회는 명시적 요청에 따라 과별로 활성화합니다.
원본 병원 문서, 실제 작성 데이터와 전문의 명단은 공개 저장소에 포함하지 않습니다.

- 마취통증의학과 지원부서: 전신마취·부위마취 건수 및 비고만 입력
- 병리팀: 특수병리·조직병리·세포병리 건수 및 비고만 입력
- 표 제목, 열 제목과 행 이름은 작성 항목의 문맥을 위해 읽기 전용으로 표시
- 책임자 성명·자격·직책, 단위만 있던 수량·면적 칸도 직접 입력 가능
- 선택항목은 라디오/체크박스와 기타 상세 입력으로 작성
- 담당 범위에 포함된 영양사·약사·보건의료정보관리사 명단에 행 추가·삭제 가능
- 진료과 23개 상단 전문의·지도전문의 표 제외

작성값은 서버에 전송하지 않습니다. 제출 JSON 파일을 저장해 담당자에게 전달하고,
담당자는 여러 제출 파일을 불러와 CSV로 취합합니다. 브라우저 임시 저장 및 파일 복원을 지원합니다.
이전 파일에 있던 담당 외 항목은 새 양식으로 불러올 때 제외합니다.

## 개발 검증

개발 저장소의 `tools/check_scoped_forms.py`에서 원본 파란색 좌표와 모든 입력 칸을 대조합니다.
36개 양식의 컨트롤 렌더링, 마취·병리 범위 제한, 책임자 성명·자격 저장 복원,
추가 명단·선택값의 파일 출력·취합, 이전 저장 자료 호환성을 Chromium에서 확인했습니다.
정적 페이지에서는 외부 패키지나 로그인 없이 사용할 수 있습니다.

명단의 추가 행 삭제 버튼은 오른쪽 ‘행 관리’ 열에 표시합니다. 기존 행의 관리 칸은 비워두며, 행 추가 버튼은 명단 아래 한 개만 둡니다.

## 집담회 및 중앙공급실

- 집담회 메뉴 → 23개 수련과 중 선택 → 과별 작성·임시 저장·제출 파일 저장
- 과와 연도가 다르면 별도 자료로 보관하며 제출 파일명과 취합 화면에서도 구분
- 중앙공급실의 세로 설명 영역을 통합해 잘못 생긴 빈 입력칸 제거
- 책임자·직원 수·면적과 원본의 시설·멸균 방법·관리 방법 항목 입력 지원
- 중앙공급실 원본 구조 17행×8열의 셀 겹침·누락을 대조 검증

수술실 연간 수술 건수 9칸은 원본의 주황색 확인 대상 칸이지만 사용자 요청에 따라 입력 가능하게 합니다. 수술실장 확인 문구는 입력 금지가 아닌 확인 메모로 제목 아래 표시합니다. 3개 수술실 구분 × 3개 마취 종류의 원본 병합 구조를 유지합니다.
